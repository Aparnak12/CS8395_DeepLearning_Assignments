# Deep Learning Assignments – CS 8395 (Spring 2024)

This repository contains solutions to programming assignments for **CS 8395: Special Topics in Deep Learning** at Vanderbilt University. Each assignment explores a distinct deep learning concept through hands-on implementation using PyTorch.

## Contents

| Homework | Topics Covered | Notebooks |
|----------|----------------|-----------|
| [HW1](./hw1) | Gradient Descent, MLPs, Bias-Variance Tradeoff | `DL_HW1_Q1.ipynb`, `DL_HW1_Q2.ipynb`, `DL_HW1_Q3.ipynb` |
| [HW2](./hw2) | MLPs on shifted signals, Data Augmentation, 1D CNN | `DL_HW2_Q3.ipynb` |
| [HW3](./hw3) | Set Networks, Vision Transformers | `DL_HW3_Q1.ipynb`, `DL_HW3_Q2.ipynb` |
| [HW4](./hw4) | GANs, Diffusion Models, Adversarial Attacks & Training | `DL_HW4_Q1.ipynb`, `DL_HW4_Q2.ipynb`, `DL_HW4_Q3.ipynb`, `DL_HW4_Q4.ipynb` |

## Key Concepts Across Assignments

- **HW1**: Optimization behavior (GD), classification with MLPs, overfitting control via bias-variance analysis.
- **HW2**: Performance of MLPs on shifted data, importance of equivariance and invariance, and architecture design.
- **HW3**: Handling unordered set inputs with permutation invariance; implementation of custom Vision Transformers.
- **HW4**: Generative models (GANs & Diffusion), adversarial attack techniques (FGSM, PGD, CW), and robustness via adversarial training.

## Frameworks Used

- Language: Python 3.x  
- Libraries: PyTorch, NumPy, Matplotlib
